## ①这种范围 for 每次只给你一个“元素的值”，不给你迭代器，也不给你下一个元素。
```
   for (int x : s) {
    // 循环体
}
```
x 是当前字符的拷贝，它跟你原字符串已经没关系了。\
你拿到 x，但拿不到 x 在字符串里的位置，也就不知道“下一个字符”是谁。

迭代器 __begin 被藏起来了，循环体里根本访问不到。\
所以没法写 *(__begin + 1) 去取下一个。

## ②正常的经典迭代器
```
for (auto it = s.begin(); it != s.end(); ++it) {
    int x = *it;
    // ...
}
```
