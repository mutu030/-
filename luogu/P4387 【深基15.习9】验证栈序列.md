先把入栈序列存进数组 n[]，用一个w 表示「下一个要进栈的位置」。<br>

对每个出栈元素 c，按三种情况判断：<br>
情况1：栈顶 == c → 直接 pop。<br>
情况2：n[w] == c（下一个将进栈的数就是它）→ w++，跳过，相当于「进栈后立刻出栈」。<br>
情况3：栈顶和 n[w] 都不是 c → 把 n[w] 不断压栈，直到栈顶 == c 或没元素可压。<br><br>

三种情况都不成立就判 No。<br>

可以看得出来波珠花了大量力气模拟栈的入栈出栈，连写了3个ifelse模拟入栈出栈顺序的可能流程。<br>
为毛标准答案用一个while就代替了<br>

## ③ 代码
```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
	
	int a;cin>>a;
	
	for(int i=0;i<a;i++){
		
		stack<int>l;
		
		int b,n[100000];cin>>b;
		
		for(int i=0;i<b;i++)cin>>n[i];
		
		int w=0;
		int y=1;          
		
		for(int i=0;i<b;i++){
			int c;cin>>c;
			
		
			if(y==0) continue;
			
			if(!l.empty() && l.top()==c){
				
				l.pop();
			}
			else if(w<b && n[w]==c){
			
				w++;
			}
			else{
			
				while(w<b && (l.empty() || l.top()!=c)){
					l.push(n[w]);
					w++;
				}
				if(!l.empty() && l.top()==c){
					l.pop();
				}else{
					y=0;
				}
			}
		}
		
		if(y) cout<<"Yes"<<endl;
		else  cout<<"No"<<endl;
	}
	
	return 0;
}
```
