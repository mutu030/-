2. 队列中重复国籍的计算


## ② 重点或不同解题方法

**本题重点（易错点）**：

虽然看上去像是***队列***维护滑动窗口的题\
但重点完全<br>①在于怎么重复国籍的计算，所以为了这个点居然需要***一个计数数组***和***int计数国籍***\
<sub><small>（ac过后查了一下题解他们似乎把计数数组这种东西叫做**桶**，负责实时统计当前窗口内每个国籍的人数。喂！不要莫名其妙弄一些没人看得懂的术语啊！要不然就写一本算法竞赛术语解析挂在首页啊！）</small></sub><br>
很奇怪吧，有了***int计数国籍***的话就不用每次都遍历***计数数组***判断国籍数了<br><br>
②超时弹出如何把根据队列里的时间，把没用的***计数数组***的数据给削去，这里需要用到***结构体***放入队列\
这样的话，弹出时可以一次性把超时时间t带的数据全弹出，重点是这些数据直接就是***计数数组***的编号,所以有了结构体就可以直接改动***计数数组***里的数，这样的话又可以通过***计数数组***的有无数来判断***int计数国籍***的加减<br><br>
t超时-> 通过数据体{t,x}改变***计数数组***的所有x-> ***计数数组***为0时***int计数国籍***减1-> 在队列里弹出超时t<br>
相当于维护了一个实时***队列***滑动窗口加一个实时***计数数组***

## ③ 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct stu{
	
	int t;
	int x;
};

int main(){
	queue<stu>l;
	
	int n[100005]={0};
	
	int a,q=0;cin>>a;
	
	for(int i=0;i<a;i++){
	
		
		int b,c;
		cin>>b>>c;
		
		

		
		
		for(int j=0;j<c;j++){
			
			int p;cin>>p;
			l.push({b,p});
			
			if(n[p]==0){
				q++;
				
			}

		n[p]++;
			
		}

		
		while(!l.empty()&&b-l.front().t>=86400){
			
			int o=l.front().x;
		
			n[l.front().x]--;
			
			l.pop();
			
			if(n[o]==0){
				q--;
				
			}
			
		}
		



		cout<<q<<endl;	
		
	}
	
	
	

	
	
	
	return 0;
}
