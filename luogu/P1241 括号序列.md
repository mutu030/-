可能总的来说这道题的样例也太怪了<br>
([()   -> () [] ()<br>
([)    -> () [] ()<br>
([)])  -> ([()])<br>
([)]   ->()[()]<br>
(][)(] ->() [] [] () () []<br>
重点是2和3样例很怪啊，真的很神人呐（样例4是最后我猜出来的），，所以重点**是在栈顶的左括号有没有匹配**<br>
很神啊！早这样说为什么不多出几个样例来模拟啊！要理解你这个括号的合法序列很难啊只给样例1，2是什么意思（尖叫跑开）<br><br>

也就是说***从左往右遍历找右括号，直到无右括号为止***，<br>

<br>重点在于**右括号不入栈，只有左括号会“留在栈里等匹配”**<br>
说实话，**右括号不入栈，只有左括号会“留在栈里等匹配”**这句话应该被挂成每个括号匹配题的qq签名<br><br>

如果没有最近的左括号，此右括号失效（该位置**标记数组**标记成为需要补全的0），如果有最近的左括号，标记为1，左括号弹出。接着往下找下一个右括号进行匹配。遍历完之后根据**标记数组**得到括号。<br>

故为**栈**加**标记数组**，除此之外，我还用了一个j维护**栈顶的标号**，最难过的就是栈顶有时候会为空，导致j=m.top()的时候一直崩溃，必须加一个if (!m.empty()) j = m.top();
