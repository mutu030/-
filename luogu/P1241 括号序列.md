可能总的来说这道题的样例也太怪了<br>
([()   -> () [] ()<br>
([)    -> () [] ()<br>
([)])  -> ([()])<br>
([)]   ->()[()]<br>
(][)(] ->() [] [] () () []<br>
重点是2和3样例很怪啊，真的很神人呐（样例4是最后我猜出来的），，所以重点**是在栈顶的左括号有没有匹配**<br>
很神啊！早这样说为什么不多出几个样例来模拟啊！要理解你这个括号的合法序列很难啊只给样例1，2是什么意思（尖叫跑开）<br><br>
也就是说***从左往右遍历找右括号，直到无右括号为止***，<br>
说实话，**右括号不入栈，只有左括号会“留在栈里等匹配”**这句话应该被挂成每个括号匹配题的qq签名
<br>重点在于**右括号不入栈，只有左括号会“留在栈里等匹配”**<br>
如果没有最近的左括号，此右括号失效（该位置标记为需要补全的0），如果有最近的左括号，标记为1，左括号弹出。接着往下找下一个右括号进行匹配。遍历完之后根据标记数组得到括号。

## ③ 代码

```
#include <iostream>
#include <algorithm>
#include <string>
using namespace std;

int a[105]; // 标记

int main()
{
    int i,j;
    string s;
    cin >> s;
    for (i=0; i<s.length(); i++) {
        if (s[i] == ')') { // 找到了右括号
            for (j=i-1; j>=0; j--) {
                if (s[j] == '(' and a[j] == 0) { // 找到了没被匹配过的左括号且匹配成功

                    a[i] = a[j] = 1;
//a[j] = 1：左括号 s[j] 已经找到了它的右括号，不用再补了。a[i] = 1：右括号 s[i] 已经找到了它的左括号，不用再补了。

                    break;
                }
                else if (s[j] == '[' and a[j] == 0) break; // 找到了左括号但匹配失败
            }
            // 找不到左括号，不做任何操作
        }
        // 下面同理
        else if (s[i] == ']') {
            for (j=i-1; j>=0; j--) {
                if (s[j] == '[' and a[j] == 0) {
                    a[i] = a[j] = 1;
                    break;
                }
                else if (s[j] == '(' and a[j] == 0) break;
            }
        }
    }
    for (i=0; i<s.length(); i++) {
        if (a[i] == 0) { // 没有匹配则成对输出
            if (s[i] == '(' or s[i] == ')') cout << "()";
            else cout << "[]";
        }
        else cout << s[i]; // 匹配成功则直接输出
    }
    return 0;
}

```
